# praxis-core

Shared Praxis libraries extracted from `v0.1.0-alpha.44` (`2ff043bac32d42b728de60e8fd969ffbac064a90`).

Packages: `@praxis/contracts`, `@praxis/cli`, `@praxis/vcs`, `@praxis/jira`, `@praxis/plugin-sdk`, `@praxis/project-config`, `@praxis/knowledge`, `@praxis/catalog`, `@praxis/testing`.

Jira and VCS are libraries here, not Desktop MCPB products. Runtime and role plugins consume these as `0.1.0-alpha.44` tgzs.

```bash
npm install
npm run verify
npm run pack:vendor
```
